## 📁 Estrutura do projeto

- `index.html`: estrutura da página.
- `style.css`: estilização do site.
- `img/`: imagens utilizadas no projeto.
- `.github/workflows/`: arquivos de automação CI/CD.
- `package.json`: dependências do projeto.
- `package-lock.json`: controle das versões das dependências.

## ⚙️ Automação CI/CD

O projeto utiliza GitHub Actions para automatizar processos de integração e publicação.

### CI — Integração Contínua

Executa automaticamente:
- Instalação das dependências.
- Validação do código HTML com HTMLHint.

### CD — Entrega Contínua

Executa automaticamente:
- Preparação dos arquivos do site.
- Publicação pelo GitHub Pages.

Os processos são acionados quando alterações são enviadas para a branch `main`.

## 💻 Como executar localmente

1. Clone o repositório:

   `git clone https://github.com/Matheuszzzx/portfolio-cicd.git`

2. Entre na pasta:

   `cd portfolio-cicd`

3. Instale as dependências:

   `npm install`

4. Abra o arquivo `index.html` no navegador.
